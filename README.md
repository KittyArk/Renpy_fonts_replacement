# Renpy_fonts_replacement
#ENG

Quick Font Replacement Using Renpy's config.font_replacement_map

Run extract_fonts.py to extract all fonts used in the game

Run list_fonts.py to list all font files in the folder

Manually modify the fonts to be replaced and their replacements in fonts_replacement.rpy

fonts_replacement all-auto.rpy will map all font types

fonts_replacement.rpy only maps configured font types; bold and italic can be specified manually

Translated with DeepL.com (free version)
